# OpenPages

Публичная площадка для сайтов Игоря. Сайты публикуются ассистентом (OpenClaw) или вручную и раздаются через **GitHub Pages**.

## Как устроено

Каждый сайт — отдельная папка в корне репозитория:

```
OpenPages/
├── index.html        ← лендинг со списком сайтов
├── sites/
│   ├── primer-1/
│   │   └── index.html
│   └── primer-2/
│       └── index.html
```

После включения GitHub Pages сайты доступны по адресам:

- Лендинг: `https://podolitoga-max.github.io/OpenPages/`
- Сайт: `https://podolitoga-max.github.io/OpenPages/sites/<имя-сайта>/`

## Как добавить сайт

1. Создать папку `sites/<имя-сайта>/`.
2. Положить туда `index.html` (и при необходимости CSS/JS/картинки).
3. Закоммитить в ветку `main` — GitHub Pages обновит сайт автоматически.

## Правила

- Репозиторий **публичный** — не размещать здесь секреты, токены, персональные данные.
- Имена папок сайтов — латиницей, в нижнем регистре, через дефис.
