Админка и права

Здесь фиксируется модель доступа: кто видит базу, кто может менять роли, кто экспортирует данные.

Админ

  • Видит все
  • Управляет пользователями
  • Экспортирует базу
  • Меняет настройки

Руководитель

  • Все лиды отдела
  • Меняет ответственных
  • Смотрит отчеты
  • Экспорт по разрешению

Менеджер

  • Свои лиды
  • Общая очередь
  • Без чужой базы
  • Без экспорта

Ассистент

  • Создает лиды
  • Видит очередь
  • Квалифицирует
  • Без денег и экспорта

Сметчик

  • После замера
  • Смета / КП
  • Ссылки на файлы
  • Без базы продаж

Просмотр

  • Только разрешенные разделы
  • Без редактирования
  • Без удаления
  • Без экспорта
